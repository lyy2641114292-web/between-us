## 问题与决策

- **问题**：原型用 CDN 版 Tailwind 在浏览器实时编译，无法直接作为可运行应用的一部分。
  → 决策：**用户确认采用方案 A** —— 安装 Tailwind 3.4.x 在构建时编译，产物为普通 CSS 文件，不依赖 CDN。498 处 class 原样保留，视觉零漂移。方案 B（全量手写 CSS）不采用。
- **问题**：原型把用户填写的数据（片段、对话气泡、反思五条）都放在 DOM 节点里，刷新即丢。
  → 决策：改造时必须全部收进 `src/state/`，这是本改造的主要工作量来源，已写入技术方案风险表。
- **决策**：不沿用任何既有项目（`between us2.0`、`情感对话`）的代码与结构，从零新建。
- **决策**：本阶段不接入真实大模型，仅在 `src/ai/provider.js` 留接口与开关。
- **体检结论**：原型零图片/零图标字体/零 data URI，视觉全由 CSS + SVG + Canvas 生成，无素材缺失风险。
- **体检风险**：字体网络可达性为最高风险（已用自托管解决）；WebGL/SVG 噪声/毛玻璃为 GPU 亚像素差异，属原型固有，不处理。
- **决策**：语音讲述改为 Web Speech API 真实录音+识别；相册上传维持模拟（不真读图、不做 OCR）。
- **决策**：不实现 `prefers-reduced-motion`，与原型行为保持一致。
- **决策**：绝不引入替代方案（Three.js / 图标库 / 动画库 / 组件库）。Tailwind 仅将编译时机从 CDN 改为构建时。

  - 先检查上一问是否被真正回答，答非所问则换说法重问，已答过绝不复问
  - 把「已问过的问题」列表显式传给模型，防止撞车

**修复的 bug**：
1. **答案错位**：`submitAnswer` 后 60ms 就请求下一问，读到旧 state。
   改为把本轮回答先合并进上下文再传参。

### 优化：追问提速 + 交互调整 + 措辞修复（用户反馈）

**用户反馈的四个问题**：
1. 追问速度太慢（实测每轮 3.5–5.4 秒）
2. 点选项或按回车应直接进入下一题
3. 阶段 02 仍是旧数据，没及时更新
4. 阶段 03「对面的人」应是第一人称引语，不是「你回应说……」这类转述

**已确认的方案**：
- 追问加速：预生成分支（AI 一次给出下一问 + 常见回答 + 对应再下一问）
- 点标签与回车都直接提交
- 阶段 02 内容变了就自动重生
- 阶段 03：对话用第一人称直接引语（不加前缀）；动作类另起文字栏，人称站当前体验视角

**实现**：

1. **预生成分支（两层）**
   - probe 提示词改为返回结构化 chips：
     `{ label, nextQuestion, nextChips: [{ label, nextQuestion, nextChips }] }`
   - store 的 `normChips` 递归规范化两层
   - 新增 `s1/pickChip`：命中带 nextQuestion 的标签 → **直接追加下一问，零等待**
   - 实测：第 1 层 647–655ms（几乎无感知），第 2 层走 API 约 4.2s

2. **交互**
   - 点标签 → `pickChip` → 直接提交并进下一问
   - 回车 → 提交（读 `e.currentTarget.value` 避免 React 状态延迟）；Shift+回车换行

3. **阶段 02 自动重生**
   - store 新增 `stage01Signature()`（基于回答内容指纹）
   - 四个阶段的 `aiSuccess` 记录 `aiSourceSignature`
   - 四个 hook 的触发条件改为：`idle`（首次）或 `aiSourceSignature !== 当前指纹`（内容变了）
   - 实测：回阶段 01 补一轮 → 再进 02 会显示加载并重生

4. **阶段 03 措辞**
   - 提示词把「已确认事件」分为两种类型：
     - `speech`：只写引语本身，禁止「你回应说」「她表示」前缀
     - `action`：动作/状态，用平实叙述，人称站当前体验视角（朋友的动作→「你」，对方的动作→「她」）
   - store 加了兜底正则，自动剥离残留的转述前缀
   - 阶段 03 渲染：`speech` 走对话气泡（加引号），`action` 走一行斜体文字栏
   - 内置模板同步更新 type 字段

**验证结果**：
- 措辞实测：
  - speech：「你每次解释都像在狡辩，一点都不近人情」
  - speech：「我是看过日历的，真的不知道为什么看错了」
  - action：「她隔很久回了"行吧"，之后一周没有找你。」
- 全链路 10 项全通过，运行时错误 0
- 回归确认无「你回应说 / 她表示 / 她认为你」类转述

### 修复：旧数据未刷新 + 五处交互/措辞问题（用户反馈）

**问题一：对话数据没刷新**
根因：存档 `VERSION` 仍是 2，旧档的 `qa` 数组结构兼容，被原样保留，
其中没有 `chips`、`nextQuestion`、`aiSourceSignature`，所以界面看起来是旧版。
修复：`VERSION` 升到 3，版本不匹配时直接丢弃旧档重新开始。

**问题二：阶段 01 标签秒切题目**
修复：改为多选。点标签只切换选中（带 ✓ 标记），
停手 1.5 秒后自动合并提交（`已选 N 项，停手 1.5 秒后自动继续`）。
用 `pickedRef` 避免定时器读到旧闭包值。

**问题三：阶段 03 角色视角混乱**
用户指出的实际错误：
- 左侧气泡标着「对面的人（原本的你）」，内容却是第三人称描述朋友
- 用户说「她深夜在线上对话里说，她认为你不在意她」已经跑到了左边

修复：
1. 提示词明确：`speech` 类型必须是**用户自己说的话**，用第一人称「我」，不加前缀
2. 提示词明确：`action` 类型人称统一为 **你 = 用户，她 = 朋友**
3. 左侧标签改为「你（自己）· 当时说的」
4. 右侧标签改为「她（朋友）· 你替她回应」
5. 页面顶部新增常驻角色说明条：`你（自己）= 原本的你 / 她（朋友）= 你正在扮演的那个人`
6. 换位觉察卡注明「这一部分切回你自己的视角」

实测输出：
- action：「你推掉了她约的饭局，理由是那天实在太累。」（你=用户，她=朋友）
- speech：「我感觉你好像不太在意我。」
- speech：「你根本就是在找借口。」

**问题四：阶段 05 两种意愿草稿没区别**
修复：
1. 提示词按意愿明确立意差异：
   - express：说出感受 + **主动了解对方**，句式「我感到…」，必须有一处问对方的处境
   - explain：说明当时的背景与动机，句式「我当时是想…」，先讲处境再讲情绪
2. store 新增 `aiIntentSignature`，记录生成时用的意愿
3. hook 检测到 `intent` 与 `aiIntentSignature` 不一致时自动重新生成

实测：
- express：「我其实挺在意的——我说『太累』的时候，希望它是被当作真的」
- explain：「我当时确实状态不好，不是找借口，也不是不想见你」

**问题五：阶段 02 交互精简**
修复：
- 去掉「点击展开」「保留为未知」「+ 补充其他可能性」
- 每条改为常显卡片（标签、AI 提问、其他可能性都直接展示）
- 每条右下角新增「就这条问问静观」入口
- 点击 → 打开静观抽屉，并把该条内容预填到输入框，聚焦待用户提问
- 新增 store action：`sp/openWithSeed`、`sp/clearSeed`，stillpoint 增加 `seed` 字段

**验证**：全链路 10 项通过（右侧气泡标签需先回答一幕才出现，属正常），运行时错误 0。

### 修复：阶段 03 人称规则（第三轮反馈，已用选项逐条确认）

**经过三轮确认，最终规则如下**：

| 位置 | 类型 | 主语 |
|---|---|---|
| 左（你自己） | speech 对话 | 我 |
| 左（你自己） | action 动作 | 他 / 原本的你 |
| 右（朋友） | speech 对话 | 你（指用户） |
| 右（朋友） | action 动作 | 你（指朋友） |

其他约束：
- 每幕只呈现这一幕新发生的内容，**不重复上一幕**
- 第三人称转述（「她说，她认为你…」）一律禁止
- 宁可留空，也不要重复或硬造

**结构改造**：
- 每幕从单一 `confirmedEvent` 改为 `self` + `friend` 双条：
  `{ self: {type, text}, friend: {type, text} }`
- 新增 `buildActStream(act)` 展开成对话流条目（带 `side: 'self'|'friend'`）
- 渲染按 `side` 分左右，按 `kind` 分气泡/动作行
- 兼容旧结构兜底：只有 `confirmedEvent` 时归到 self 一侧

**验证实测**：
- 第 1 幕 左[action]「他看错了日历，跟她说那天有事」/ 右[speech]「你真的有把这件事放在心上吗」
- 第 2 幕 左[speech]「我是看过日历的，真不知道为啥看错了」/ 右[action]「你过了很久才回，语气很冷」
- 第 3 幕 左[speech]「再解释也没用」/ 右[action]「你不再多说什么」
- 浏览器渲染确认：左侧「你（自己）· 当时说的」，右侧「她（朋友）· 她说的」，无转述
