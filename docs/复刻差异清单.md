## 0. 检查结论摘要

原型 **零图片、零视频、零图标字体、零 data URI**，全部视觉由 CSS + 内联 SVG + Canvas 生成。
因此不存在素材丢失问题，这也是高保真复刻可行的根本原因。

- 可 100% 复刻：布局、配色、29 个材质类、25 组关键帧、shader、粒子、SVG 星图
- 无法保证 100%：6 项（见第 2 节），其中 3 项已由用户决策（见第 3 节）
- 绝不替代：7 类（见第 4 节）

## 2. 无法保证 100% 一致的 6 项

### 2.1 字体的网络可达性 —— 风险最高
- **原因**：原型从 `fonts.googleapis.com` 加载 4 个字族共 14 个字重；国内常连不上或极慢，失败即回退系统字体，标题衬线质感与中文细字重明显变化。
- **影响**：这是唯一会让产品「看起来像换了一个」的偏差。
- **决策**：自托管（见 3.1）。

### 2.2 WebGL 等高线与 SVG 纸张肌理的亚像素差异
- **原因**：渲染由显卡驱动决定；`feTurbulence` 噪声、抗锯齿在不同 GPU 上有亚像素级差异。
- **影响**：风格与构图完全一致，截图放大逐像素对比不完全相同。
- **性质**：原型固有属性，非改造引入。不处理。

### 2.3 `backdrop-filter` 模糊强度差异
- **原因**：24 处毛玻璃的模糊半径由浏览器/GPU 实现，存在轻微视觉差异。
- **影响**：Chrome / Edge 在 Windows 上一致；Firefox 旧版本可能不支持。
- **应对**：保留原型的声明顺序与 `-webkit-` 前缀（原型已有 12 处），不额外降级。

### 2.4 SMIL 动画（5 处 `<animateMotion>`）
- **原因**：沿路径运动的能量光点使用 SVG 原生动画；Chrome / Edge 正常，Safari 有已知时序问题。
- **影响**：与原型一致（原型即此写法）；若未来主攻 Safari，需改用 JS 驱动。
- **应对**：不处理，与原型保持一致。

### 2.5 原型自身的非标 Tailwind 数值 —— 第 1 步已核实完毕
- **核实结果**：
  - `duration-400`（1 处）：Tailwind v3 默认刻度为 `0/75/100/150/200/300/500/700/1000`，**没有 400**。原 CDN 版同样不生成 → **原型中该类本就是空的**，悬停为瞬间跳变。
  - `opacity-55`（1 处）、`opacity-85`（2 处）：属于 v3 默认刻度 → 原型中正常生效。
- **决策**：**不补 `duration-400` 刻度**。若补上，反而会与原型的「无过渡」行为不一致。
- **状态**：已闭环，无需用户决策。

### 2.6 两处「模拟」交互的真伪
- **现象**：原型中「语音讲述」只是往输入框塞预置文字，「相册上传」只塞预置对话片段；均不录音、不读图。
- **决策**：语音改为真实录音 + 识别（见 3.2）；相册维持模拟（见 3.3）。

## 3. 用户已确认的决策（2026-11-15）

### 3.1 字体：自托管
- 把 4 个字族共 14 个字重装进项目，放 `public/fonts/` 或经 npm 字体包引入，`@font-face` 自声明。
- 断网可用、部署后不受网络影响，字形与原型一致。
- 代价：项目体积增加约 10–20MB，首屏首次加载稍慢（后续走缓存）。
- 注意：Noto Sans SC / Noto Serif SC 为 CJK 字体，体积大，按需只装用到的 3 个字重。

### 3.2 语音：改为真实录音 + 识别
- 使用浏览器内置 Web Speech API（`SpeechRecognition`），不引入第三方语音服务、不产生费用。
- 可用范围：Chrome / Edge。不可用时按钮保留但提示「当前浏览器不支持语音识别，请用文字输入」，不报错、不白屏。
- 需要处理：麦克风权限授予/拒绝、识别中状态、识别失败、用户中途取消。
- 隐私：识别在本浏览器内发起，不落盘、不上传本项目服务器（本项目无服务器）。
- 已知限制：识别准确度一般，可能需用户手动修正文字。原型的「预置文案」行为被替换为真实转写。

### 3.3 相册上传：维持模拟
- 保持与原型一致：选择文件后写入预置片段提示。
- 明确不做：真实读图、OCR、从截图提取对话。图片内容不上传、不存储。

### 3.4 减少动画设置：不做适配
- 不实现 `prefers-reduced-motion`，与原型行为完全一致。
- 已从 `docs/设计规范.md` 的 7.5 条移除该要求。

### 3.5 阶段 01 防连点：新增 300ms 守卫（与原型不同）
- **用户决策（2026-11-15）**：点选标签与「记录并继续」均加 300ms 防连点。
- **与原型差异**：原型无任何防抖，快速连点会提交多条相同片段。
- **涉及位置**：`src/stages/Stage01Capture.jsx` 的 `pickChip` 与 `submit`。
- **范围**：仅阶段 01。其余阶段若出现同类误触，需另行确认后再加。

### 3.6 阶段 01 可回改：上一题 / 重新开始 / 时间线编辑（新增功能，原型没有）
- **用户需求（2026-11-15）**：记录冲突时无法回退修改，希望有修改空间。
- **新增三处能力**：
  1. **「← 上一题」按钮**：步骤 2~4 时显示，返回上一题并把该题原内容回填到输入框，可直接改后重新记录。
  2. **「↻ 重新开始」按钮**：有片段时显示，二次确认后清空**本阶段**片段（不影响其他阶段）。
  3. **时间线可回改**：每条片段标注「第 N 题 · 题目名」，点击标签可跳回该题；悬停显示「改 / 删」，可就地编辑或删除单条。
- **数据结构变化**：`stage01.fragments` 由 `string[]` 改为 `{id, text, step}[]`；存档版本号 v1 → v2。
- **旧存档兼容**：读取 v1 存档时自动迁移（按顺序推断每条所属步骤），用户数据不丢。
- **去重逻辑**：同一题重复提交会**覆盖**该题原有片段，不会产生重复条目。
- **与原型差异**：原型只能一路向前，无法回退或修改；此功能为主动增强。

### 3.7 阶段 03 改为「角色互换纯对话」（主动偏离原型，2026-11-16 用户指定）

- **原型做法**：三幕固定剧本，每幕一条「已确认事件」+ 4 个回应选项；选项里混有动作/心理描写（如「（停顿了三四秒，握着手机不知道该怎么接话，只是轻轻叹了口气）」），bridge 文案也带旁白（「这句话像一块石头投入水面……」）。
- **新规则**（用户逐条指定）：
  1. **只有纯对话**，不生成任何旁白、动作、心理描写。
  2. 左侧气泡固定为「原来的你」，右侧气泡固定为「朋友（她）」。
  3. 输出结构固定为 `{ chat[], question, options[], done }`：
     - `chat` 为纯对话行，`role: "left"` =「原来的你」说的话，`role: "right"` =「朋友（她）」说的话
     - `question` 必须带明确主语（如「站在朋友的位置……」）
     - `options` 为**四个情绪角度**草稿：`[{ key, text }]`，`key` 为 2~4 字关键词，`text` 为 1~2 行台词
  4. 轮数不再固定三幕，**由 AI 判断对话够了即收尾**，随后显示换位觉察卡。
  5. 四个草稿可点选，**同时保留自由输入框**（用户可自己写朋友的话）。
  6. 收尾轮额外返回 `insightHint`（一句引导语）与 `insights`（4 个觉察项）：**引导语与觉察项按本次对话内容生成**，人称只用「你」与「朋友」。
- **随之移除**：动作行渲染、`bridge` 过渡旁白、「已确认事件」标签。
- **人称基线**（用户三轮确认，见开发日志 2026-11-15）：用户此刻扮演「朋友（她）」，所以页面上「原来的你」不再是「你」。页面标签须统一为「原来的你」/「朋友（她）」，不得再用「你（自己）」。
- **2026-11-16 用户验收后补充**：
  - 03 页顶部「角色互换：左侧 · 原来的你 / 右侧 · 朋友（她） / 此刻由你来演她」说明栏**整块删除**（轨道头图已含角色信息）。
  - 橙色气泡标签「原来的你 · 原本的你说的」→「原来的你 · 你说的」。
  - 回应区由 A/B 两项改为**四个情绪角度**（原「A = 表达感受并了解对方，B = 解释自己的想法」的固定语义作废）。
  - 换位觉察卡：人称只用「你」与「朋友」（不出现「她」）；删掉「这一部分切回你自己的视角：你 = 你自己，她 = 朋友（她）」小字；引导语与 4 个觉察项由 AI 按本次对话生成，不再用写死文案。
- **与原型差异**：这是**功能性偏离**，视觉材质类、双色语义、轨道头图与动画仍按原型保留。

### 3.8 阶段 05 草稿立意与反思长度（2026-11-16 用户指定）

- **原型做法**：四种意愿共用同一份固定草稿模板，`switchS5Tone` 只换三种语气的文案，与意愿无关。
- **新规则**：
  1. **意愿不同，草稿各有侧重**（允许重叠，但主次必须不同）：

     | | express（表达感受并了解对方） | explain（解释自己的想法） |
     |---|---|---|
     | 主体 | 我的感受 | 我当时怎么想、为什么那样做 |
     | 陪衬 | 背景可带一句，不展开 | 感受可带一句，不展开 |
     | 必含 | 一处了解朋友的句子 | 一处交代当时想法的句子 |
     | 结尾 | 邀请朋友说 | 不施压，不追问 |

     两份草稿都可以提到对方的要素，只是主体与落点不同；不能只换几个词。
  2. **五条反思每条 ≤30 字**，只留一个核心判断，像便签而不是段落。
- **不变**：三种语气（坦诚且温和 / 更轻盈简短 / 不给对方压力）仍只负责长度与施压程度，不改变侧重。
- **与原型差异**：属**文案质量约束**，页面结构与视觉不变。

## 4. 绝不替代清单（用户要求：不用别的同款替代）
| 原型所用 | 绝不替换为 |
|---|---|
| 手写 WebGL GLSL shader | Three.js / PixiJS / 任何 3D 库 |
| 原生 Canvas 2D 粒子 | 粒子库（tsparticles 等） |
| 内联 SVG 图形 | 图标库（lucide / heroicons 等） |
| Tailwind CSS | UnoCSS / Windi / 其他原子化框架 |
| CSS `@keyframes` 动画 | GSAP / Framer Motion / anime.js |
| CSS `transition` 过渡 | 任何动画封装库 |
| 手写 `<button>` + class | 组件库（shadcn / MUI / Ant Design 等） |
| 原生 `localStorage` | 状态持久化库（zustand persist 等） |
| 原型既有文案 | 任何改写、润色、扩写 |

**唯一允许的"替换"**：把 Tailwind 从「浏览器 CDN 实时编译」改为「构建时编译」——同一个 Tailwind、同一套 class、同一份配置，只是编译时机不同，产物为普通 CSS 文件。原型中 498 处 class 一字不改。
