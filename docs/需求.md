## 1. 项目目标

把 Between Us 的高保真 HTML 原型，转为可在浏览器真正运行的 Web 应用：
先在本机运行验证，后续可部署为公开网址；数据只存在当前设备的浏览器里；AI 角色留出接入真实大模型的接口。

面向：正在为一段友情冲突反复内耗、想理清「事实 / 感受 / 对方可能视角」的人。

## 2. 使用场景

- 用户在深夜反复回想一次冲突，打开页面，从「记录冲突」开始逐段写下片段，不一次讲完。
- 用户写完事实后，区分「客观发生的事」与「自己脑中的解读」，把部分解读搁置为「未知」。
- 用户与「原来的你」做角色互换对话：用户扮演她（朋友），AI 扮演原来的你；只有对话，没有旁白，觉察自己作为她最难接哪一句。
- 用户并排对照双方视角，看到「我以为」与「她可能」的差异，含明确的「尚不确定」留白。
- 用户决定下一步（表达 / 解释 / 保持距离 / 暂不决定），得到一段可复制的表达草稿。
- 全程可随时点开「静观」侧栏，让第三方视角陪自己梳理。

## 4. 非功能需求

- **视觉零漂移**：改造前后逐屏对比，不允许出现布局、字号、间距、颜色差异。
- **性能**：首页 WebGL + 2D 双画布保持流畅；页面隐藏时暂停动画循环。
- **隐私**：全部数据只在本机浏览器；不做任何上报；导出文件由用户自己保存。
- **内容约束（沿用原型的产品立场，不得改动）**：
  1. 不生成用户没说过的话；对方视角一律用假设措辞。
  2. 不判断冲突双方对错；不替用户决定是否修复关系。
  3. 情境逐段呈现，不一次性铺开大量背景。
- **兼容**：Chrome / Edge 最新版优先；移动端布局按原型的响应式断点。

详细差异与「绝不替代」清单见 `docs/复刻差异清单.md`。
